# CodeAlpha Internship Project – Video Game Sales Analysis

## 📌 Project Overview
This project was completed as part of the **CodeAlpha Data Analytics Internship**.  
It focuses on **Exploratory Data Analysis (EDA)** and **Data Visualization** using the **Video Game Sales dataset**.

The dataset contains information about 64,000+ video game titles released between 1971–2024, including:
- Game Name
- Platform
- Genre
- Publisher
- Year of Release
- Regional Sales (NA, EU, JP, Other)
- Global Sales

---

## 🎯 Objectives
- Perform **EDA** to identify trends, patterns, and anomalies in video game sales.
- Build **interactive dashboards** in Power BI to visualize insights.
- Highlight key findings that support data-driven decision-making.

---

## 🛠 Tools & Technologies
- **Power BI Desktop** (Data Cleaning, EDA, Visualization)
- **Power Query** (Data Transformation)
- **GitHub** (Version Control & Submission)

---

## 📊 Key Insights
1. Action and Sports genres dominate global sales.
2. Peak sales occurred around **2008**, followed by a decline.
3. **Nintendo platforms** lead in Japan, while **PlayStation** dominates Europe.
4. Outliers like *Wii Sports* show unusually high global sales compared to other titles.

---

## 📈 Dashboard Features
- **Global Sales Trend Over Time** (Line Chart)
- **Sales by Genre** (Bar Chart)
- **Regional Sales Comparison** (Stacked Bar Chart)
- **Top 10 Games by Global Sales** (Column Chart)
- **Platform vs Global Sales** (Bar Chart)
- Interactive **Slicers** for Year, Genre

---

## 🚀 How to Use
1. Download the `.pbix` file from this repository.
2. Open it in **Power BI Desktop**.
3. Explore the dashboard using slicers and filters.
4. Review insights and replicate analysis for other datasets.
